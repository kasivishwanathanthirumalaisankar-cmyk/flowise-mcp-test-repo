# Daily To-Do App

A simple Node.js app to manage daily tasks.

## Features
- Add tasks
- Mark tasks as done
- Delete tasks
- View today's tasks

## Setup
1. Clone this repository:
   ```bash
git clone https://github.com/kasivishwanathanthirumalaisankar-cmyk/flowise-mcp-test-repo.git
   ```

2. Install dependencies:
   ```bash
   cd flowise-mcp-test-repo
   npm init -y
   npm install express body-parser
   ```

3. Run the app:
   ```bash
   node app.js
   ```

4. Access the app:
   Open [http://localhost:3000](http://localhost:3000) in your browser.
